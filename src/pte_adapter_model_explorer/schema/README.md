# Bindings for Executorch schemas

## Flatbuffer schema files

The flatbuffer schema files contained in this directory were taken from v1.0.0 of Executorch here:

- https://github.com/pytorch/executorch/blob/v1.0.0/schema/scalar_type.fbs
- https://github.com/pytorch/executorch/blob/v1.0.0/schema/program.fbs
- https://github.com/pytorch/executorch/blob/v1.0.0/backends/xnnpack/serialization/schema.fbs

## Python bindings

The python bindings for the above flatbuffer schemas were generated by `scripts/flatbuffer-gen.sh` where flatbuffer's version was `v25.12.19` and are saved in `src/pte_adapter_model_explorer/executorch_flatbuffer`.

These should be re-generated every time we change either ExecuTorch's or flatbuffer's version.
